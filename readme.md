# 🐱 MetaCat – A Semi-Async Search Engine written in PHP

> *Vibe-coded for fun, fueled by curiosity, and held together by duct tape and async dreams.*

MetaCat is an experimental, semi‑asynchronous search engine built with **PHP** and **AmPHP**. It was created as a learning project – most of the code was generated by AI (“vibe coding”), so expect rough edges, architectural inconsistencies, and a few “it works on my machine” moments.  

---

## ✨ Features (such as they are)

- **Semi‑async crawling** – Uses AmPHP’s event loop for concurrent HTTP requests, but don’t look too closely at the rest.
- **Indexing** – Basic inverted index (likely stored in a simple DB).
- **Search endpoint** – A naive query parser that returns matching URLs.
- **Blocker‑logger** – The logger is *synchronous* and *blocking*, because mixing paradigms is part of the fun(Frankly I was so lazy to make the logger async :|).
- **All in PHP** – No Node.js, no Go, just pure PHP.

---

## 🧠 Motivation

This project was never meant to be production‑ready. It exists to:
- Learn how to work with AmPHP in PHP.
- Understand the basic building blocks of a search engine (crawler → indexer → ranker → query).
-assisted Experiment with AI‑ coding (“vibe coding”) – the AI wrote most of it, I just kept hitting “accept”.
- Have something that can actually search a small set of pages, even if slowly and inconsistently.
